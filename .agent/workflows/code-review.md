# 🔍 코드 검토 요청 가이드

## 검토 요청 시점
- 모든 기능 구현 완료 후
- 버그 수정 후
- 대규모 리팩토링 후

## 검토 요청 방법

### 1. 터미널에서 다른 AI 실행
```powershell
# Claude 실행
claude

# 또는 Gemini 실행
gemini
```

### 2. 검토 요청 템플릿
```
아래 코드를 검토해줘.

### 구현 내용
- [구현한 기능 요약]

### 검토 요청 사항
- 버그가 있는지
- 보안 취약점이 있는지
- 더 나은 방법이 있는지

### 관련 파일
- [파일명] ([설명])
```

### 3. 파일 내용 확인 명령어
```powershell
# 파일 전체 보기
Get-Content [파일명]

# 마지막 N줄만 보기
Get-Content [파일명] -Tail 100

# 특정 범위 보기
Get-Content [파일명] | Select-Object -Skip 100 -First 50
```

### 4. 검토 결과 적용
- AI가 변경을 제안하면 옵션 선택:
  - `1` = 이번만 적용
  - `2` = 세션 동안 자동 적용
  - `4` = 거절

## 예시: 로그인 시스템 검토 요청
```
script.js의 마지막 120줄에 있는 고객 로그인 시스템 코드를 검토해줘.
- 1분 세션 타이머가 정확히 작동하는지
- localStorage 저장이 안전한지
- 에러 처리가 누락된 곳이 있는지
```
