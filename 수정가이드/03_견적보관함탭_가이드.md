# 📦 견적 보관함 탭 수정 가이드

> 저장된 견적을 확인하고 관리하는 화면입니다.

---

## 1. 섹션 헤더

| 명칭 | 설명 | 수정 예시 |
|------|------|----------|
| **섹션 제목** | "견적 보관함" 텍스트 | "제목을 '내 견적'으로 변경해줘" |
| **섹션 설명** | "저장된 견적을 확인해보세요." | "설명 문구 변경해줘" |

---

## 2. 견적 리스트

| 명칭 | 설명 | 수정 예시 |
|------|------|----------|
| **견적 카드** | 저장된 견적 개별 카드 | "카드 디자인 변경해줘" |
| **차량 이미지** | 카드 내 차량 썸네일 | "이미지 크기 조정해줘" |
| **차량명** | 모델명 텍스트 | "폰트 크기 키워줘" |
| **견적 금액** | 저장된 렌탈료 | "가격 강조해줘" |

---

## 3. 빈 상태 (Empty State)

| 명칭 | 설명 | 수정 예시 |
|------|------|----------|
| **빈 상태 아이콘** | 박스 아이콘 | "아이콘 변경해줘" |
| **빈 상태 메시지** | "보관된 견적이 없습니다." | "메시지 변경해줘" |
| **차량 구경 버튼** | "차량 구경하러 가기" 버튼 | "버튼 색상 변경해줘" |

---

## 4. 견적 상세 보기

| 명칭 | 설명 | 수정 예시 |
|------|------|----------|
| **목록으로 버튼** | "< 목록으로" 뒤로가기 | "버튼 텍스트 변경해줘" |
| **상세 차량 이미지** | 큰 차량 이미지 | "이미지 영역 확대해줘" |
| **상세 차량명** | 차량 모델명 | "폰트 스타일 변경해줘" |
| **최종 월 렌탈료** | 최종 가격 표시 박스 | "가격 박스 디자인 변경해줘" |
| **아코디언 컨테이너** | 상세 조건 펼침 영역 | "아코디언 스타일 변경해줘" |
| **FAQ 섹션** | 자주 묻는 질문 (상세용) | "FAQ 내용 수정해줘" |
| **필요서류 탭** | 개인/사업자/법인 탭 | "탭 스타일 변경해줘" |
| **상담 신청 버튼** | "상담 신청하기" 버튼 | "버튼 문구 변경해줘" |

---

## 📍 화면 구조도

### 리스트 화면
```
┌─────────────────────────────────┐
│  견적 보관함                     │ ← 섹션 헤더
│  저장된 견적을 확인해보세요.     │
├─────────────────────────────────┤
│  ┌─────────────────────┐        │
│  │ 🚗 차량1            │        │ ← 견적 카드
│  │ 월 000,000원        │        │
│  └─────────────────────┘        │
│  ┌─────────────────────┐        │
│  │ 🚗 차량2            │        │
│  │ 월 000,000원        │        │
│  └─────────────────────┘        │
├─────────────────────────────────┤
│ 홈 | 분석 | 보관함 | 가이드 | 후기│
└─────────────────────────────────┘
```

```
│                                 │
│         📦                      │
│  보관된 견적이 없습니다.         │ ← 빈 상태
│  [차량 구경하러 가기]           │
│                                 │
├─────────────────────────────────┤
│ 홈 | 분석 | 보관함 | 가이드 | 후기│
└─────────────────────────────────┘
```
