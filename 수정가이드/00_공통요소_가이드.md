# 🎨 공통 요소 수정 가이드

> 모든 탭에서 공통으로 사용되는 UI 요소입니다.

---

## 1. 하단 네비게이션 바

| 명칭 | 설명 | 수정 예시 |
|------|------|----------|
| **네비게이션 바** | 화면 하단 고정 메뉴 | "네비게이션 배경색 변경해줘" |
| **홈 탭** | 🏠 홈 버튼 | "홈 아이콘 변경해줘" |
| **렌탈료 분석 탭** | 📊 분석 버튼 | "탭 이름 변경해줘" |
| **견적 보관함 탭** | 📦 보관함 버튼 | "아이콘 변경해줘" |
| **이용가이드 탭** | 📖 가이드 버튼 | "탭 순서 변경해줘" |
| **출고 후기 탭** | ⭐ 후기 버튼 | "탭 숨기고 싶어" |
| **활성 탭 표시** | 선택된 탭 강조 스타일 | "활성 색상 변경해줘" |
