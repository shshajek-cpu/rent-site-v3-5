# 🏠 홈 탭 수정 가이드

> 메인 차량 리스트가 표시되는 첫 화면입니다.

---

## 1. 헤더 영역

| 명칭 | 설명 | 수정 예시 |
|------|------|----------|
| **페이지 타이틀** | "차량 견적 리스트" 텍스트 | "타이틀을 '장기렌트 견적'으로 변경해줘" |
| **브랜드 필터** | 브랜드 로고 가로 스크롤 | "브랜드 순서 변경해줘" |
| **로그인 상태 바** | 로그인 후 사용자 정보 표시 | "로그인 바 색상 변경해줘" |

---

## 2. 검색 영역

| 명칭 | 설명 | 수정 예시 |
|------|------|----------|
| **검색창** | 차량명/등급 검색 입력 필드 | "placeholder 변경해줘" |
| **검색 아이콘** | 돋보기 아이콘 | "아이콘 색상 변경해줘" |
| **검색 결과 요약** | "전체 차량 0대" 텍스트 | "폰트 크기 키워줘" |

---

## 3. 카운트다운 배너

| 명칭 | 설명 | 수정 예시 |
|------|------|----------|
| **배너 전체** | 파란색 프로모션 배너 | "배너 배경색 변경해줘" |
| **메인 텍스트** | "특판할인" 텍스트 | "문구 변경해줘" |
| **마감임박 텍스트** | 빨간색 "마감임박" 텍스트 | "색상 변경해줘" |
| **서브텍스트** | "할인 가능 적용 잔여 수량" | "다른 문구로 바꿔줘" |
| **카운터 숫자** | 실시간 숫자 표시 | "숫자 스타일 변경해줘" |

---

## 4. 차량 카드 목록

| 명칭 | 설명 | 수정 예시 |
|------|------|----------|
| **차량 카드** | 개별 차량 정보 카드 | "카드 디자인 변경해줘" |
| **차량 이미지** | 카드 상단 차량 사진 | "이미지 비율 조정해줘" |
| **차량명** | 모델명 텍스트 | "폰트 굵기 변경해줘" |
| **등급 정보** | 트림/등급 표시 | "등급 색상 변경해줘" |
| **렌탈료** | 월 렌탈료 금액 | "가격 강조해줘" |
| **카드 그리드** | 카드 배열 방식 | "한 줄에 2개씩 보여줘" |

## 6. 로그인 팝업

| 명칭 | 설명 | 수정 예시 |
|------|------|----------|

## 📍 화면 구조도

```
┌─────────────────────────────────┐
│  [페이지 타이틀]                 │ ← 헤더
│  [브랜드 필터 스크롤]            │
├─────────────────────────────────┤
│  🔍 [검색창]                     │ ← 검색 영역
│  전체 차량 N대                   │
├─────────────────────────────────┤
│  특판할인 마감임박  [카운터]     │ ← 카운트다운 배너
├─────────────────────────────────┤
│  ┌─────┐ ┌─────┐                │
│  │차량1│ │차량2│                │ ← 차량 카드 목록
│  └─────┘ └─────┘                │
│  ┌─────┐ ┌─────┐                │
│  │차량3│ │차량4│                │
│  └─────┘ └─────┘                │
├─────────────────────────────────┤
│ 홈 | 분석 | 보관함 | 가이드 | 후기│ ← 하단 네비게이션
└─────────────────────────────────┘
```
