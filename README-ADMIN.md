## 🎯 시스템 개요

**Car Manager Admin Dashboard**는 차량 렌탈 서비스를 위한 관리자 전용 대시보드입니다.

### 핵심 특징
- ✅ **보안**: 로그인 인증 시스템 (세션 기반)
- ✅ **완전한 CRUD**: 차량 등록/조회/수정/삭제 지원
- ✅ **사용자 친화적**: 토스트 메시지, 실시간 검증
- ✅ **이미지 업로드**: Base64 인코딩으로 로컬 저장
- ✅ **반응형 디자인**: PC/태블릿/모바일 모두 지원

---

## 🌟 주요 기능

### 1. 보안 인증
- 관리자 로그인 시스템
- 세션 만료 관리 (2시간)
- 비인가 접근 차단

### 2. 차량 관리
| 기능 | 설명 |
|------|------|
| **등록** | 새 차량 추가 (브랜드, 모델, 가격, 이미지 등) |
| **조회** | 전체 목록 + 검색 + 통계 대시보드 |
| **수정** | 기존 차량 정보 변경 |
| **삭제** | 차량 제거 (확인 다이얼로그 포함) |

### 3. 고급 기능
- 🖼️ **이미지 업로드**: 파일 선택 시 자동 Base64 변환 (최대 5MB)
- ✅ **실시간 검증**: 가격, URL 입력 시 즉시 확인
- 🔔 **토스트 알림**: 성공/에러/경고 메시지 UI
- 📊 **통계 카드**: 전체 차량 수, 평균 렌탈료, 신차 수
- 🔍 **검색 기능**: 브랜드/모델명 실시간 필터링

## 🚀 빠른 시작

### 1단계: 로그인
1. `admin-login.html` 파일을 브라우저에서 열기
2. 다음 계정으로 로그인:
   - **아이디**: `admin`
   - **비밀번호**: `admin1234`

### 2단계: 차량 등록
1. 좌측 사이드바에서 **"차량 등록하기"** 클릭
2. 필수 정보 입력:
   - 브랜드 (드롭다운)
   - 모델명
   - 스펙/등급
   - 월 렌탈료
3. 이미지 업로드 (선택사항)
   - "파일 선택" 버튼 클릭
   - 또는 URL 직접 입력
4. **"등록하기"** 버튼 클릭

### 3단계: 차량 관리
1. **"차량 목록 관리"** 메뉴 클릭
2. 검색창에서 브랜드/모델 검색 가능
3. 각 차량의 수정/삭제 버튼 사용

## 🛠️ 기능별 사용법

### 📝 차량 등록 (admin.html)

**입력 검증 규칙:**
- ✅ 가격: 0보다 크고 1억 이하
- ✅ 이미지 파일: 5MB 이하, 이미지 형식만
- ✅ URL: HTTP/HTTPS 프로토콜만 허용

**자동 처리:**
- ID는 UUID로 자동 생성
- 입력란 벗어날 때 실시간 검증
- 이미지 선택 시 미리보기 표시

### 📊 차량 목록 (admin-list.html)

**통계 대시보드:**
- 전체 차량 수
- 평균 렌탈료
- 신차 수량

**검색 기능:**
- 브랜드명 검색 (예: "현대", "BMW")
- 모델명 검색 (예: "그랜저", "E-Class")
- 실시간 필터링

**테이블 기능:**
- 브랜드별 색상 뱃지
- 이미지 표시 (또는 기본 아이콘)
- 수정/삭제 버튼

### ✏️ 차량 수정 (admin-edit.html)

**수정 가능 항목:**
- 모든 필드 수정 가능
- 기존 이미지 유지 또는 새 이미지 업로드
- 실시간 미리보기

### 🔒 보안 기능 (auth.js)

**세션 관리:**
- 로그인 시 2시간 세션 생성
- 만료 시 자동 로그아웃
- 브라우저 닫아도 세션 유지 (LocalStorage)

**페이지 보호:**
- 모든 관리 페이지는 로그인 필수
- 비인가 접근 시 로그인 페이지로 리다이렉트

## 🔧 커스터마이징

### 관리자 계정 변경
`auth.js` 파일에서 수정:
```javascript
const ADMIN_CREDENTIALS = {
    username: 'admin',        // 원하는 아이디로 변경
    password: 'admin1234'     // 원하는 비밀번호로 변경
};
```

### 세션 시간 변경
```javascript
const SESSION_DURATION = 2 * 60 * 60 * 1000; // 밀리초 단위 (현재 2시간)
```

### 브랜드 추가
`admin.html`, `admin-edit.html`의 select 옵션에 추가:
```html
<option value="tesla">테슬라 (Tesla)</option>
```

그리고 `admin-list.js`의 `brandNames` 객체에 추가:
```javascript
const brandNames = {
    // ... 기존 브랜드
    tesla: '테슬라'
};
```

## ⚠️ 중요 참고사항

### LocalStorage 제한사항
- **용량**: 브라우저당 약 5~10MB
- **영속성**: 브라우저 캐시 삭제 시 소실
- **공유**: 다른 PC에서 데이터 접근 불가

### 프로덕션 환경 권장사항
1. **백엔드 서버 구축** (Node.js + Express, Firebase 등)
2. **실제 데이터베이스 연동** (PostgreSQL, MongoDB 등)
3. **JWT 기반 인증** 또는 OAuth
4. **이미지 CDN 사용** (Cloudinary, AWS S3 등)
5. **HTTPS 필수**

## 🐛 문제 해결

### 로그인이 안 돼요
- 아이디/비밀번호를 정확히 입력했는지 확인
- 브라우저 캐시 삭제 후 재시도

### 이미지 업로드가 안 돼요
- 파일 크기가 5MB 이하인지 확인
- 이미지 파일 형식인지 확인 (JPG, PNG, GIF 등)

### 데이터가 사라졌어요
- LocalStorage는 브라우저 캐시 삭제 시 소실됩니다
- 개발자 도구 (F12) → Application → Local Storage에서 확인 가능

### 모바일에서 레이아웃이 깨져요
- 브라우저 캐시 새로고침 (Ctrl + F5)
- admin.css 파일이 올바르게 로드되었는지 확인
